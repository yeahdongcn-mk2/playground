# 路线图

路线图按“先验证底座，再扩类型，最后做平台能力”的顺序推进。每个阶段都有可验证的退出条件，避免为了堆游戏而堆游戏。

## M0 · 底座 + 贪食蛇（本次交付）

- [x] Vite 8 + TypeScript 7 + 严格类型检查
- [x] 大厅、Hash 路由、共享页头/页脚、音效开关
- [x] `GameModule` 契约、游戏注册表、动态加载
- [x] 纯逻辑贪食蛇引擎 + 单元测试
- [x] Phaser 4 渲染、键盘/触屏/滑动输入、暂停/重开
- [x] 最高分持久化、合成音效、`aria-live` 状态播报
- [x] Playwright 端到端测试、CI、构建产物包体记录
- [x] 框架选型、架构、设计文档

**退出条件**：`npm run typecheck && npm run test:unit && npm run build && npm run test:e2e` 全部通过；大厅首屏 gzip < 50 KB；贪食蛇可完整游玩一局。

## M1 · 第二个 2D 游戏：霓虹打砖块

目标：验证“复用 2D 适配层”而不只是复制贪食蛇。

- 新建 `games/breakout/`，逻辑与渲染分离；
- 复用大厅样式、HUD、暂停/重开/最高分/音效约定；为大厅卡片补一张打砖块插画；
- 引入关卡数据（JSON 或 TS 常量）与道具雏形；
- 复用 Phaser chunk（浏览器缓存），确认新增游戏的边际包体；
- 端到端覆盖：开局、丢球、过关、最高分。

**退出条件**：新增游戏不需要修改 `core/`；共享 UI 至少复用 80%；新增 chunk gzip < 450 KB。

## M2 · 首个 3D 游戏：立体迷宫（Three.js）

目标：验证 3D 适配器与共享契约，确认 2D/3D 并存不会污染大厅。

- 新增 `three` 依赖并只在 `games/maze/` 动态导入；
- 实现相机、移动、碰撞、计时、通关；
- 在 `destroy()` 中释放 renderer、geometry、material、texture 与事件监听；
- 页面隐藏时暂停渲染循环；
- 记录 3D chunk 体积与帧率（目标 60 FPS，移动端 30+）；
- 端到端覆盖：进入/退出、键盘移动、暂停、通关/失败。

**退出条件**：大厅首屏体积不增长（引擎仍懒加载）；3D chunk gzip < 800 KB；2D 游戏回归通过。

## M3 · 平台能力

在保持纯静态部署的前提下，按收益排序：

1. **本地排行榜/成就**：localStorage 记录多局成绩、最高连击、首胜等；不引入后端。
2. **全局设置**：音效、减少动效、键位提示；统一存储在共享 settings 命名空间。
3. **游戏手柄**：Gamepad API 适配层，仅对支持的游戏启用。
4. **每日挑战**：使用日期作为种子（`createSeededRng`）生成固定食物序列，天然可分享、可复现。
5. **PWA / 离线**：Service Worker 预缓存大厅和已玩过的游戏 chunk。
6. **性能面板**：开发环境显示 FPS/包体提示，便于后续游戏调优。

**退出条件**：每项能力都有测试与文档；新增平台能力不要求游戏代码重复实现。

## M4 · 可选：在线能力

只有在出现明确需求时才考虑：

- 账号 / 云存档；
- 在线排行榜（防作弊需要服务端权威逻辑）；
- 多人对战（WebSocket / WebRTC，延迟与状态同步是独立课题）。

这些会改变“纯静态、无后端”的约束，需要单独立项，不在当前框架承诺内。

## 框架复核点

以下任一情况出现时，重新评估 [ADR-001](./framework-selection.md)：

- 2D 游戏数量 ≥ 5，Phaser chunk 缓存或包体成为瓶颈；
- 3D 游戏数量 ≥ 3，Three.js 的工程化基础设施（资源、物理、编辑器）明显不足；
- Phaser 4 或 Three.js 出现破坏性升级，迁移成本高于切换成本；
- 需要单引擎统一编辑/发布流程（例如商业化发行）。

## 风险登记

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| Phaser chunk 较大（363 KB gzip） | 首局加载稍慢 | 仅进入游戏时加载；后续可加预取提示/Service Worker |
| 两套引擎增加维护面 | 升级与文档成本 | 引擎只出现在各自游戏内；共享契约稳定；按游戏独立升级 |
| 触屏/键盘输入差异 | 移动端体验 | D-pad + 滑动 + 移动端视口模拟测试（真实设备手工验收） |
| localStorage 被禁用 | 最高分丢失 | `StorageService` 容错，游戏继续运行 |
| 缺少视觉回归 | UI 回归靠人工 | 关键布局指标断言 + 截图归档；后续可引入截图对比 |
| 3D 尚未验证 | 3D 规划可能与现实不符 | M2 以真实 3D 游戏验收，再更新架构文档 |
